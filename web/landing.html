Straight from this server, no app store, no account with anyone else. Use the same sign-in everywhere.

Windows

Windows 10 and 11, 64-bit

Push to talk that works in game, tray icon, notifications and automatic updates.

Checking…

Windows may say it "protected your PC" because the app isn't code-signed. Click More info → Run anyway.

Android

Android 7 and newer

Tap the download, then open it. If Android asks, allow installs from this source (your browser) once.

Checking…

Got a very old test build and Android says "App not installed"? Uninstall Outhouse once, then install this one. Updates install over the top after that.

iPhone, Mac and everything else

Any modern browser

Outhouse runs right in your browser. On iPhone or iPad, open it in Safari, tap Share → Add to Home Screen and it behaves like an app, notifications and all.

Open in browser

On Android, Chrome's ⋮ → Install app works too.
